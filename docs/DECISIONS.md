- 2026-10-24 ASR: Muse Voice Transcribe (`wss://api.meta.ai/v1/asr/realtime`) streams, supports Tamil with code-switching, keyword biasing and diarization, but returns NO word timestamps. Both implemented behind `ASR_PROVIDER`; default `muse` (Meta-native, handles Tanglish, same key as the LLM); `deepgram` is the fallback.
