# KIN decisions log (one line each, newest at the bottom)

- 2026-10-24 Heritage language for the demo family is Tamil (demo speaker speaks it).
- 2026-10-24 VERIFIED Meta Model API: base `https://api.meta.ai/v1`, bearer `MODEL_API_KEY`, chat completions at `/chat/completions`, structured output via `response_format={"type":"json_schema","json_schema":{name,schema,strict}}`; strict mode needs `additionalProperties:false` and all keys in `required`. Source: dev.meta.ai/docs/structured-output, /docs/protocols/chat-completions.
- 2026-10-24 Default LLM is `muse-spark-1.3` (same price and limits as 1.1; 1.1 and 1.2 remain available). Plan said 1.1; one env var (`LLM_MODEL`) switches back.
- 2026-10-24 Muse Spark always reasons; `reasoning_effort` set to `low` for live translation to protect the latency budget. `stop`, `logprobs`, `n>1` are rejected by the API, so the client never sends them.
- 2026-10-24 Prompt caching on Meta Model API is automatic prefix caching; the family-graph context goes first in the system prompt, utterance last. `prompt_cache_key="kin"` sent as a routing hint.
- 2026-10-24 Meta Model API exposes NO embeddings endpoint (checked /docs/api-reference and pricing). Entity linking uses alias tables + rapidfuzz fuzzy matching; memory search uses SQLite FTS5. Embeddings are optional behind `EMBEDDINGS_PROVIDER` (none by default) so no torch download during the hackathon.
- 2026-10-24 ASR: Muse Voice Transcribe (`wss://api.meta.ai/v1/asr/realtime`) streams, supports Tamil with code-switching, keyword biasing and diarization, but returns NO word timestamps. Deepgram nova-3 supports Tamil (`language=ta`) with word timestamps and `keyterm`, but Tamil is NOT in Deepgram `multi` code-switching (en, es, fr, de, hi, ru, pt, ja, it, nl only). Both implemented behind `ASR_PROVIDER`; default `muse` (Meta-native, handles Tanglish, same key as the LLM); `deepgram` is the fallback.
- 2026-10-24 TTS: ElevenLabs WebSocket `wss://api.elevenlabs.io/v1/text-to-speech/{voice_id}/stream-input`, header `xi-api-key`; model `eleven_flash_v2_5` (~75 ms, supports Tamil) for live speech, `eleven_multilingual_v2` for glossary audio. Voice clone only with recorded consent.
- 2026-10-24 Transport: no LiveKit key on the team yet, so the plan's FALLBACK (16 kHz PCM over a plain WebSocket between two browser clients and FastAPI) is the primary transport. LiveKit agent remains an optional module behind `TRANSPORT=livekit`.
- 2026-10-24 Phone bridge (Phase 5): Twilio ConversationRelay, two independent relay sessions bridged in-app (Twilio's own human-to-human translation tutorial pattern). Relay does STT (Deepgram) and TTS (ElevenLabs) itself; KIN supplies grounded text. VERIFY Tamil language code (`ta-IN`) in ConversationRelay voice configuration before Phase 5.
- 2026-10-24 Database: SQLite via SQLAlchemy by default (`DATABASE_URL`), Postgres a URL change away. Graph stored as nodes + edges tables, not Neo4j.
- 2026-10-24 Frontend: Vite + React + TypeScript rather than Next.js. Nothing needs SSR; Vite scaffolds and reloads faster.
- 2026-10-24 Build machine has Python 3.12 and 3.14; venv uses 3.12 for wheel coverage; project targets >=3.11.
- 2026-10-24 Dependencies: fastapi/uvicorn (API + websockets), sqlalchemy (DB), pydantic-settings (env), openai (OpenAI-compatible client for Meta Model API), httpx + websockets (raw provider clients, fewer SDK pins), rapidfuzz (romanization-tolerant alias matching), twilio (TwiML + outbound call), pytest + pytest-asyncio (tests).
